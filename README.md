# ShopNest Live — বাংলা ইকমার্স স্টার্টার

এটি আগের লোকাল ডেমোর পরবর্তী ধাপ: Express সার্ভার, SQLite ডেটাবেস, পাসওয়ার্ড-হ্যাশ করা অ্যাডমিন অ্যাকাউন্ট, সার্ভার-সাইড স্টক যাচাই এবং আলাদা স্টোর/অ্যাডমিন পেজ।

## ফিচার
- কাস্টমার স্টোর: প্রোডাক্ট, সার্চ, কার্ট, অর্ডার ফর্ম
- অ্যাডমিন লগইন: সেশন কুকি, পাসওয়ার্ড bcrypt hash, login rate limit
- ড্যাশবোর্ড: প্রোডাক্ট/অর্ডার/অর্ডার মূল্য/পেন্ডিং হিসাব
- প্রোডাক্ট যোগ, এডিট, ডিলিট; নাম, বিবরণ, ক্যাটাগরি, দাম, স্টক, ছবি
- অর্ডার তালিকা, স্ট্যাটাস আপডেট, ডিলিট
- SQLite-তে প্রোডাক্ট ও অর্ডার; SQLite-তেই সেশন স্টোর
- ছবির ধরন ও ২MB সাইজ সীমা; HTTP security headers

## লোকালি চালাতে
1. Node.js 20 বা নতুন ভার্সন ইনস্টল করুন।
2. এই ফোল্ডারে টার্মিনাল খুলুন।
3. `.env.example` কপি করে `.env` নামে রাখুন।
4. `.env`-এ `ADMIN_USERNAME`, `ADMIN_PASSWORD` (কমপক্ষে ১২ অক্ষর), এবং `SESSION_SECRET` সেট করুন। `SESSION_SECRET`-এ দীর্ঘ র‍্যান্ডম মান দিন।
5. চালান:
   ```bash
   npm install
   npm start
   ```
6. স্টোর: `http://localhost:3000`
7. অ্যাডমিন: `http://localhost:3000/admin.html`

প্রথমবার সার্ভার চালুর সময় `.env`-এর অ্যাডমিন অ্যাকাউন্ট তৈরি হবে। আগে অ্যাডমিন তৈরি না হলে সঠিক পরিবেশ ভেরিয়েবল দিয়ে আবার চালান।

## অনলাইনে প্রকাশের আগে
- HTTPS ব্যবহার করুন এবং `NODE_ENV=production` সেট করুন।
- স্থায়ী ডিস্ক/ভলিউম যুক্ত করুন: `data/` এবং `public/uploads/` অবশ্যই deploy/restart-এর পরেও টিকে থাকতে হবে। ephemeral filesystem-এ SQLite ও আপলোড ছবি হারিয়ে যেতে পারে।
- `SESSION_SECRET`-কে দীর্ঘ, গোপন random string করুন; শক্তিশালী অ্যাডমিন পাসওয়ার্ড ব্যবহার করুন।
- ডেটাবেস ও আপলোডের নিয়মিত ব্যাকআপ নিন।
- অনলাইন পেমেন্ট, কুরিয়ার, SMS, কাস্টমার অ্যাকাউন্ট, পাসওয়ার্ড পরিবর্তনের UI এখনো যুক্ত নয়।
- প্রোডাকশন চালুর আগে ডিপ্লয়মেন্ট পরিবেশে টেস্ট, লগ/মনিটরিং, ব্যাকআপ রিস্টোর ও নিরাপত্তা পর্যালোচনা করুন।

## গুরুত্বপূর্ণ
এই ZIP নিজে থেকে কোনো পাবলিক URL-এ প্রকাশিত হয়নি। হোস্টিং অ্যাকাউন্ট ও ডিপ্লয়মেন্ট সেটআপ ছাড়া লাইভ লিংক তৈরি করা যায় না। অ্যাডমিন URL `/admin.html`; শুধু URL লুকিয়ে রাখা নিরাপত্তা নয়—API-তে লগইন যাচাই আছে।
